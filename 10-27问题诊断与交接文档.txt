article.tsx - lessonId 获取逻辑
// article.tsx 第32行
const { lessonId } = (route?.params as { lessonId?: string }) ?? {};
问题点：

如果 route 为 undefined，route?.params 返回 undefined
undefined as { lessonId?: string } 类型断言可能导致问题
?? {} 会将 undefined 替换为 {}，但 { lessonId } 从空对象中提取会是 undefined
更严格的修复：

const routeParams = route?.params ?? {};
const { lessonId } = routeParams as { lessonId?: string };
// 或者
const { lessonId }: { lessonId: string } = route?.params ?? {};
featured.tsx - 导航参数传递
// featured.tsx 第99-103行
router.push({
  pathname: "/article",
  params: { lessonId: lesson.id },
} as any)
关键检查：

lesson.id 是否真的有值？
router.push 是否真的执行了？
expo-router 是否正确传递了 params？

2. 问题原因详解
1. article.tsx - route.params 获取不健壮
原始代码：

const { lessonId } = (route?.params as { lessonId?: string }) ?? {};
问题：

当 route 为 null 或 undefined 时，route?.params 返回 undefined
undefined as { lessonId?: string } 类型断言可能掩藏问题
?? {} 会用空对象替代，但从空对象中提取 lessonId 得到 undefined
改进后的代码：

// 安全获取 lessonId，分步验证
const routeParams = route?.params ?? {};
const { lessonId }: { lessonId: string } = routeParams ?? {};
// 或者使用更安全的解构
const lessonId = route?.params?.lessonId;

问题：
